# Security

## Reporting a vulnerability

Email **security@bates-solutions.com** with "Security" and the repository name in the subject.
Please don't open a public issue for a vulnerability.

Include what you found, how to reproduce it, and what it lets someone do. You will get a reply
within 2 business days, and we will keep you updated until it is fixed. We credit reporters who
want to be credited.

## Supported versions

Security fixes go into the latest release. For a package, that is its latest major version.

A repository with its own `SECURITY.md` uses that one instead.
